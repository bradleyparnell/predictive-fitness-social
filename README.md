# Predictive Fitness Social

Social media creative assets and content strategy for **RunDot** and **TriDot**.

## Structure

```
assets/
  rundot/   — Branded mockups + logo (RunDot)
  tridot/   — Branded mockups + logo (TriDot)
strategy/   — Full social media strategy doc
```

## Four Content Pillars
| Pillar | Focus |
|--------|-------|
| 🔥 Engage | Emotion-first, community, stories |
| 🧠 Educate | Science, training tips, insights |
| 🏆 Prove It | Results, testimonials, social proof |
| 📲 CTA | Problem-aware calls to action |

## Brands
- **RunDot** — AI-powered run training. Ambassador: Meb Keflezighi.
- **TriDot** — AI-powered triathlon training. Legends: Mark Allen, Craig Alexander, Mirinda Carfrae, Tim O'Donnell.
